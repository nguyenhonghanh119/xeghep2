# Cổng tài xế XeGhép

ASP.NET Core Razor Pages + Minimal API .NET 8, C#, HTML/CSS/JavaScript thuần, MySqlConnector và cùng MySQL `xeghep_db`.

Luồng chính: đăng ký/OTP, tải 9 giấy tờ, chờ Admin duyệt, nhận/từ chối phân công, duyệt booking, xác nhận tiền mặt, bắt đầu/hoàn thành chuyến, ví/thu nhập/rút tiền, thông báo và đánh giá hành khách. Các endpoint `.php` cũ được giữ làm alias tương thích.

Xem hướng dẫn cấu hình và chạy VS Code tại [README gốc](../README.md).
